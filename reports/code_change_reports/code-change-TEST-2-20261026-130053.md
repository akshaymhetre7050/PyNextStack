## Defect Summary
`user_exists()` reports "not found" when only one of email/username is already taken.

## Root Cause Analysis
`app/routers/users.py:18-26` built `{"$or": [{"email": e, "username": u}]}`. A single-element `$or` is equivalent to AND, so a match required both fields.
Verified impact on `main`: the startup unique indexes prevent an actual duplicate document. A duplicate-email registration returned **500** (DuplicateKeyError swallowed by `except Exception`), and `/check_user_exists` returned `false` for a taken email.

## Confluence Context Referenced
None. Space `SD` only contains a Saleor overview page.

## Fix Details (Before → After)
| File | Location | Before (Defective) | After (Fixed) | Reason |
|---|---|---|---|---|
| app/routers/users.py | user_exists:19-25 | `query = {}`; `query["email"]=…`; `{"$or": [query]}` | `conditions = []`; `conditions.append({"email": …})`; `{"$or": conditions}` | One disjunct per field means a match on either field is detected |
